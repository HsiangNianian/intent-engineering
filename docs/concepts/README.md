# Concepts

This directory will hold stable definitions for intent, outcome, success criterion,
constraint, priority, authority, evidence, ambiguity, and escalation.

It is also the learning entry point for readers new to Agent intent. Each concept should eventually
include a plain-language explanation, one valid example, one counterexample, and its boundary with
the other Agent Engineering layers.

The first invariant is that an LLM may draft an intent specification, but it cannot grant
itself authority or silently resolve a material human value choice.

The implementation is an executable reference prototype for testing these definitions. It is not
evidence that the vocabulary is complete or suitable for production governance.
